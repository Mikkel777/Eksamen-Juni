# Tiltak for å redusere risiko

## Tilgangskontroll

Systemet bruker roller for å begrense tilgang til funksjoner.

* Elev
* Lærer
* Admin

## Kryptering av passord

Passord lagres kryptert med bcrypt.

## Logging

Innloggingsforsøk logges for å kunne oppdage mistenkelig aktivitet.

## Sikkerhetskopi

Databasen bør sikkerhetskopieres jevnlig for å redusere risiko ved datatap.

## Oppdateringer

Server og programvare bør holdes oppdatert for å redusere kjente sårbarheter.
