# Plan for versjonskontroll

## Verktøy

Prosjektet bruker Git og GitHub til versjonskontroll.

## Arbeidsmetode

Utviklingen deles opp i mindre oppgaver som registreres som Issues på GitHub.

Eksempler på oppgaver:

* Opprette brukerhåndtering.
* Lage innlogging.
* Lage sakssystem.
* Lage adminfunksjoner.
* Lage autentiseringslogging.

## Commit-rutiner

Det skal gjøres commits jevnlig under utviklingen.

Eksempler:

* Opprettet User-modell.
* Lagt til innlogging.
* Opprettet Ticket-modell.
* Lagt til opprettelse av saker.

## Fordeler

* Endringer kan spores.
* Tidligere versjoner kan gjenopprettes.
* Arbeidet blir lettere å dokumentere.
